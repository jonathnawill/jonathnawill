### 🏎️ iRace Engineer

**Creator of [iRace Engineer](https://www.iraceengineer.com/)** — a race engineer software for **iRacing**.

The application reads telemetry in real time and helps drivers make decisions during races, including:

* ⛽ Fuel consumption analysis
* 📊 Fuel strategy
* 🏁 Pit strategy
* 🛞 Tire strategy
* 🔔 Race notifications
* 🤖 Automatic fuel management
* 📈 Telemetry analysis
* 💾 Race history and statistics

The project combines **real-time telemetry processing, strategy algorithms, desktop application development and automation**.

One of the fuel-engine validation tests achieved approximately **0.27% error compared with ground-truth data**, and the automatic fuel strategy was validated during an actual 45-minute race.

🔗 https://www.iraceengineer.com/
